## 📱 Descripción del proyecto

Este proyecto tiene como propósito desarrollar una aplicación móvil orientada a mejorar la gestión de inventarios de repuestos críticos utilizados en el área de insertado de Virutex Ilko.

La solución busca facilitar el registro, consulta y seguimiento de los repuestos disponibles, permitiendo contar con información más organizada y oportuna para apoyar las actividades relacionadas con el control de inventarios.

---

## 🎯 Objetivo

Implementar una aplicación móvil para mejorar la gestión de inventarios de repuestos críticos en el área de insertado de Virutex Ilko, contribuyendo a reducir errores en los registros y facilitar el seguimiento de la disponibilidad de los repuestos.

---

## 🔎 Problemática

Actualmente, la gestión de algunos repuestos críticos puede involucrar procesos manuales de registro y consulta de información.

Esta situación puede generar inconsistencias en los registros, dificultades para conocer la disponibilidad de los repuestos y retrasos en los procesos de reposición.

Por esta razón, se plantea el desarrollo de una solución móvil que permita centralizar y facilitar la gestión de esta información.

## 📋 Funcionalidades del proyecto

Entre las funcionalidades contempladas para la aplicación se encuentran:

- 🔐 Autenticación de usuarios.
- 📦 Consulta de repuestos.
- 📊 Consulta de existencias.
- 🔄 Registro y seguimiento de movimientos de inventario.
- ⚠️ Alertas relacionadas con el inventario.
- 📈 Visualización de indicadores.
- 📝 Gestión de información de los repuestos.

> Las funcionalidades se encuentran en proceso de desarrollo y validación.
